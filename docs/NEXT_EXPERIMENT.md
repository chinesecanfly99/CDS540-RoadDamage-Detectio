本轮已恢复原划分的全量数据与评估链路，未重新训练。旧 n/s 权重的实际训练上限/早停分别为 50/12 和 25/10，不能把其差异直接归因于模型规模。近似场景已跨入旧训练和验证/测试集合，旧模型不能用于证明新划分的测试独立性。

## 数据前提

1. 以当前 `data/manifests` 为原始 v1 备份；不要原地修改或覆盖旧权重。
2. 从 `results/revalidation_2026-10-16/near_duplicate_pairs.csv` 复核全部候选。将同场景/相关帧归为 group；记录依据和无法确认的关系。美国完全相同的那对图像有部分框坐标不一致，应先复核规范标注再定义去重版本，不自动指定任一份为正确真值。感知筛查会漏检，不能宣称已找到所有拍摄序列。
3. 建立 data-v2 的独立清单，按 group 划分，保持源域国家覆盖及四类分布；has_target 根据四类 XML 统计。美国保留跨域角色，不参与阈值和增强选择。
4. 保存每张图的 group、split、图像/标签哈希及生成配置，验证已知组不跨集合。划分冻结后，所有模型从官方通用预训练权重重新训练，不能从可能见过新 test 的旧项目权重继续微调后声称测试独立。

## 只增加一项改进

优先验证“适量运动模糊训练增强”，因为旧材料中模糊场景的退化明显；这是待验证假设。控制组与改进组使用同一模型、数据、预算、seed、优化器和其他增强，唯一变化是预先固定的模糊概率/核大小。建议先限定 p=0.15、水平核 k=3 或 5；保存实现及参数，不把测试扰动强度拿来反复挑训练配置。

在冻结的 val 子集上使用完全相同图片比较 clean 与 blur，再决定是否进入最终实验；最终 test 只在配置冻结后评估。报告总体 AP、D40 AP/Recall、固定阈值 F1、背景误报率、处理耗时；若某项提升但 clean 退化，也要保留结果。没有实测收益就不能把它写成有效创新。
