## 执行顺序

```mermaid
flowchart TD
  A[确认任务边界与课程口径] --> B[目标环境最小推理试跑]
  B --> C[核对标注与冻结数据划分]
  C --> D[恢复旧实验依据或建立新基线]
  D --> E[比较模型与一项针对性改进]
  E --> F[冻结模型与阈值后统一评估]
  F --> G[接入人工复核规则与网页Demo]
  G --> H[不同环境独立离线验收]
  H --> I[报告 PPT 演练与提交]
  B -.提前打通界面与输入输出.-> G
  H -.发现兼容问题回修.-> B
```

阶段文件放在 [stages](stages/) 目录。每阶段只有一份 Markdown，包含目标、计划、实现、验证；不要为同一阶段再拆四份重复文档。实施时按“当前阶段通过验收后进入下一阶段”推进。UI 兼容性试跑从早期开始。
