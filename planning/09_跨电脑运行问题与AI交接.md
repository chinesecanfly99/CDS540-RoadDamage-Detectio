## 环境与最小命令

从项目根目录运行，推荐 Python 3.10/3.11。新电脑创建独立虚拟环境并安装 requirements.txt；按目标设备安装可用的 PyTorch，先以 CPU 验证链路。检查 torch、torchvision、ultralytics、opencv-python、numpy、pandas、Pillow 的实际版本及 pip check。不要复制另一台电脑的 .venv；本机现有环境复用了全局包，不是独立环境验收模板。

```bash
python scripts/predict_image.py --source "path/to/road.jpg" --output ".local/image-01" --device cpu
python demo/demo.py --source "path/to/images-or-video" --output ".local/demo-01.mp4" --device cpu --max-frames 120
```

将 path/to/... 替换为真实输入；输出名称每次换新。单图应生成 prediction.jpg/json；离线演示生成视频和 JSON。图片目录生成图片序列，不是连续行车视频。无框不等于无损坏；本机计时不代表其他设备性能。

## 数据与正式评估

现有清单路径使用 DGS2022数据/国家/国家/train/...，而 data/README 的推荐路径是 data/raw/...；转换脚本尚无统一 raw-root 参数。必须先有意适配路径并确认图/XML成对，不能按推荐目录解压后盲目运行。全量转换、回投影与实际尺寸抽检仍待验证。

准备好 data/yolo/ 后：

```bash
python scripts/evaluate_baseline.py --model models/baseline_best.pt --data configs/data.yaml --split test --output .local/eval-n-01 --device cpu
python scripts/evaluate_domain_shift.py --output .local/domain-01 --device cpu
python scripts/benchmark_runtime.py --source "path/to/raw-images" --output .local/bench-01 --device cpu --warmup 5 --runs 50
python -m unittest discover -s tests -v
```

完整评估可能较慢，应按目标先小规模验证。小规模数据只用 --purpose smoke 并明确标记，不能冒充全集。正式评估记录模型哈希、数据版本、split、imgsz、candidate-conf、NMS IoU、rect、batch 和设备；AP 汇总 PR 不等于固定部署阈值 PR。阈值只能在 val 选择，冻结后再测 test。
